An entry for the [Rename the Planet](https://make.fun/c/u-motasimfuad-rename-the-planet-094b0369) bounty on make.fun.

`main.py` writes a single one-line rename of a planet in our solar system, with the why in the same line, to `/output/entry.txt`:

> Venus is now 'The Planet That Works Backwards' — one day there outlasts a whole year, so it is always late for its own birthday.

The why earns the name: Venus really does spin so slowly that one of its days (about 243 Earth days) lasts longer than one of its years (about 225 Earth days).

## Run

```sh
python3 main.py
```
